# Sistem Pakar Diagnosis Kerusakan Smartphone dan Tablet

Aplikasi sistem pakar untuk membantu pengguna mengidentifikasi kemungkinan kerusakan smartphone dan tablet berdasarkan gejala yang dialami.

## Teknologi

- Python
- Django
- SQLite
- HTML, CSS, dan Bootstrap
- Metode Forward Chaining

## Cakupan Sistem

Perangkat yang didukung:

- Smartphone
- Tablet

Kategori kerusakan awal:

- Battery Issue
- Screen Crack
- Speaker Malfunction
- Software Crash
- Overheating

## Metode

Sistem menggunakan metode Forward Chaining. Fakta berupa gejala yang dipilih pengguna akan dicocokkan dengan aturan dalam basis pengetahuan untuk menghasilkan kemungkinan diagnosis.
